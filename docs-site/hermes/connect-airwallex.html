Connecting your Airwallex account

How to link your own Airwallex account to Hermes so the assistant can send your customers a checkout link and the money lands with you.

Money goes to your account, not ours. Hermes never holds your funds. You connect your own Airwallex account, and every payment a customer makes settles directly there. 41 Labs bills you separately — that is a different screen and has nothing to do with this one.

Before you start

You will need:

  • An Airwallex account, with permission to view API keys (in Airwallex: Developer → API keys).
  • Access to your Hermes workspace as an owner or admin.
  • About 10 minutes. You can stop after Step 5 and finish later — nothing breaks half-done.

Don't have your keys yet? You can skip all of this for now. An unconnected workspace runs on 41 Labs' shared test sandbox, so you can rehearse the entire sales flow — including a real Airwallex-hosted checkout page — without connecting anything. No real money moves, and test payments never count towards your sales figures.

What Hermes will ask you for

FieldRequired?Where to find it in Airwallex
Client IDYesDeveloper → API keys. Shown in the clear so you can check it's the right account.
API keyYesDeveloper → API keys. Treat this like a password.
Webhook secretOptionalDeveloper → Webhooks, after you create the endpoint in Step 7.
Default currencyYesYour choice — the currency your prices are quoted in.

Airwallex needs both the Client ID and the API key — one without the other will not connect.

Step by step

01

Open the Payments screen

In Hermes, go to Settings → Payments. If you don't see Settings, ask whoever set up your workspace to make you an admin.

02

Choose Airwallex

In the Provider dropdown, select Airwallex. A hint appears underneath telling you where the keys live in Airwallex.

Already connected to Stripe? Hermes will warn you before you switch. Your stored Stripe keys do not work for Airwallex and will be replaced, and new payment links go through Airwallex the moment you save — so you'll need to set up the webhook in Airwallex too (Step 7).

03

Rehearse in Sandbox first (recommended)

Under Mode, leave Sandbox selected and press Save. Send yourself a test conversation and take a test payment end to end. Nothing is charged and nothing shows up in your revenue figures.

When you're happy it works, come back and continue from Step 4.

04

Switch to Live

Under Mode, press Live. The credential fields only appear in Live mode — that's deliberate, because Sandbox doesn't use your keys at all.

Demo and live Airwallex keys look identical. Hermes cannot tell them apart, so the Mode you pick here is what decides which Airwallex account is used. Pick the one your keys actually belong to. Get it wrong and the connection fails when you test it — it won't fail silently later.

05

Get your credentials from Airwallex

In a separate tab, sign in to Airwallex and go to Developer → API keys. Copy your Client ID and your API key.

If your Airwallex login can't see that page, someone with admin rights on the Airwallex account will need to fetch them for you.

06

Paste them in and test

Back in Hermes, paste the Client ID and API key into their fields, then press Test connection.

Hermes signs in to Airwallex with the pair right there and back. Nothing is charged and no customer is affected — it's purely a check that the keys work.

You should see✓ Connected (LIVE mode)
If it failsSee If something goes wrong below.
07

Register the webhook in Airwallex

This is how Airwallex tells Hermes a customer has actually paid. Without it, a payment succeeds but the conversation never updates and the sale isn't recorded.

Copy the Webhook URL Hermes shows you (there's a Copy button next to it) — it looks like this:

https://aisalescloser.41labs.ai/api/webhooks/payments/<your-workspace-id>

In Airwallex, go to Developer → Webhooks, create a notification endpoint with that URL, and subscribe it to these three events:

payment_intent.succeeded    payment_intent.failed    refund.succeeded
08

Paste the webhook secret back into Hermes

When Airwallex creates the endpoint it gives you a secret. Copy it into the Webhook secret field in Hermes.

It's technically optional, but without it Hermes can't verify that an incoming payment notification genuinely came from Airwallex. Set it.

09

Set your default currency

Pick the currency your prices are quoted in from the Default currency dropdown.

10

Save

Press Save. The screen should now show Airwallex as connected, in Live mode, with your API key masked.

11

Turn on the Payment Link tool

One last thing, and it's easy to miss: connecting the account doesn't by itself let the assistant send a pay link.

Go to Brain Lab and enable the Payment Link tool in the conversation stages where you want the assistant to be able to ask for payment.

How to know it's really working

Run one real, small transaction — charge yourself the smallest amount your business would ever bill. Then check all three:

  • The payment appears in your own Airwallex dashboard.
  • The conversation in Hermes updates to show it was paid.
  • The sale shows up in your Hermes revenue figures.

If the money arrives in Airwallex but Hermes doesn't notice, the webhook (Steps 7–8) is the thing to re-check.

If something goes wrong

What you seeWhat it usually means
✗ Airwallex rejected the credentialsThe Client ID and API key aren't a matching pair, or they belong to the other account type — demo keys in Live mode, or live keys in Sandbox. Check the Mode you picked in Step 4.
✗ Airwallex needs a Client ID as well as the API keyThe Client ID field is empty. Airwallex needs both.
Connected, but payments never show up in HermesThe webhook isn't registered, points at the wrong URL, or is missing the three events. Redo Steps 7–8.
The assistant never offers to take paymentThe Payment Link tool isn't switched on for that conversation stage. See Step 11.
Screen says "shared test sandbox"You're still in Sandbox mode. Switch to Live and connect your keys (Steps 4–6).

Good to know

  • Your API key is stored encrypted and is never shown back to you in full — only a masked version, so you can confirm which key is in place.
  • You can disconnect at any time using the Disconnect button. The assistant falls back to the test sandbox and stops being able to take real payments.
  • Changing provider later is a fresh connection, not an edit — the new provider needs its own keys and its own webhook.
  • Never send your API key by email or chat. Enter it directly into the Hermes screen. Nobody at 41 Labs needs to see it.
