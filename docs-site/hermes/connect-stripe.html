Connecting Stripe

Connecting your Stripe account

At the end of this guide, the assistant can send a Stripe checkout link, and a completed payment shows in Hermes.

Stripe reads test or live from the key itself. A key that starts sk_test_ takes no real money. A key that starts sk_live_ charges real customers.

Before you start

You need:

  • A Stripe account, with permission to read API keys (Developers → API keys).
  • Your Hermes workspace, with the admin role. Other roles cannot open this screen.
  • About 10 minutes. You can stop after Step 5 and continue later.

What Hermes asks you for

FieldRequired?Where to find it in Stripe
Secret keyYesDevelopers → API keys. It starts with sk_live_ or sk_test_. Treat it like a password.
Webhook signing secretOptionalDevelopers → Webhooks, after you add the endpoint in Step 6. It starts with whsec_.
Default currencyYesYour choice. It is the currency of your prices.

Stripe needs one key only. The screen shows no Client ID field.

Step by step

01

Open the Payments screen

  1. In Hermes, go to Settings → Payments.
  2. In the Provider list, select Stripe.

A line below the list reads Stripe Dashboard → Developers → API keys.

A change of provider replaces the stored keys. The screen warns you first. New payment links go through Stripe as soon as you save, so add the webhook in Stripe as well (Step 6).

02

Rehearse on the shared sandbox

This step is optional, and we recommend it.

  1. Under Mode, select Sandbox.
  2. Press Save.
  3. Send yourself a test conversation, and pay the test checkout page.

Sandbox runs on the shared 41 Labs test account. It asks you for no keys, and a test payment stays out of your sales figures.

A grey Sandbox button means this deployment has no shared Stripe test account. Ask your 41 Labs contact to add one, or go to Step 3.

03

Put Hermes into Live mode

Under Mode, press Live. The key fields and the webhook fields appear. Sandbox hides them, because it reads none of them.

04

Copy your secret key from Stripe

  1. In a second tab, sign in to Stripe.
  2. Go to Developers → API keys.
  3. Copy the Secret key, and paste it into the Secret key field in Hermes.

Copy the secret key, not the publishable key. Hermes cannot create a checkout page with a publishable key.

The key wins over the Mode button. An sk_test_ key stays in test mode, and takes no real money. To take real payments, paste a key that starts sk_live_.

05

Confirm Stripe accepts the key

Press Test connection. Hermes asks Stripe about the key, and charges nothing.

A live key shows✓ Connected (LIVE mode)
A test key shows✓ Connected (TEST mode)
A bad key showsA red line. Go to If something goes wrong below.
06

Register the webhook in Stripe

The webhook tells Hermes that a customer paid. Without it, the customer pays, and the conversation and the sales figures do not change.

  1. Next to Webhook URL, press Copy. The address has this shape:
https://aisalescloser.41labs.ai/api/webhooks/payments/<your-workspace-id>
  1. In Stripe, go to Developers → Webhooks, and add an endpoint with that address.
  2. Subscribe the endpoint to these three events:
checkout.session.completed    charge.refunded    charge.dispute.created

The last two events void a sale after a refund or a dispute, so your revenue figures stay correct.

07

Store the webhook signing secret

Stripe shows a signing secret for the new endpoint. It starts with whsec_.

Copy it into the Webhook signing secret field in Hermes. The field is optional. Without it, Hermes rejects every payment message from Stripe, so set it.

08

Set the default currency

In the Default currency list, select the currency of your prices.

09

Save the connection

Press Save. The screen now reads Currently using Stripe, with the badge Connected · own account. The key field shows the last four characters only.

10

Let the assistant send a pay link

A connected account does not let the assistant ask for payment. Turn the tool on as well.

  1. Go to Brain Lab.
  2. Turn on the Payment Link tool for each conversation stage that can ask for payment.
11

Confirm a real payment arrives

Pay yourself the smallest amount you bill. Then check all three:

  • The payment shows in your Stripe dashboard.
  • The conversation in Hermes shows the payment.
  • The sale shows in your Hermes revenue figures.

Money in Stripe, and nothing in Hermes, points at the webhook. Do Steps 6 and 7 again.

If something goes wrong

What you seeWhat to do
✗ Stripe rejected the keyCopy the secret key again from Developers → API keys. A publishable key, a deleted key or a part of a key fails here.
✗ Could not reach StripeCheck your network, and press Test connection again.
That key is a TEST key, but LIVE mode was selectedPaste a key that starts sk_live_, or press Sandbox under Mode.
Going live needs this workspace’s own Stripe accountThe Secret key field is empty. Do Steps 3 and 4.
Switching to Stripe needs Stripe’s own keysPaste a Stripe Secret key before you save. A stored key of another provider does not carry over.
The badge reads Using our shared demo accountYou are still on the sandbox. Do Steps 3 to 5, then save.
Payments never show in HermesCheck the endpoint address and the three events in Stripe. Do Steps 6 and 7 again.
The assistant never asks for paymentTurn on the Payment Link tool for that conversation stage. See Step 10.

Checklist

Good to know

  • Hermes stores your secret key encrypted, and shows you the last four characters only.
  • Press Disconnect to remove the keys. The assistant returns to the shared sandbox, and stops taking real payments.
  • Send your secret key to nobody. Type it into the Hermes screen only.
  • To rotate the key, paste the new key and press Save. The webhook endpoint in Stripe stays as it is.
