# 41 Closer landing page: proof assets manifest

Compiled 2026-09-11. Every asset below traces to a cited source. Nothing here is invented.
Naming rules come from `41 Labs/sales-sop/6-CASE-STUDIES.md`: ACH, Ace Drive/Hertz and Druk Asia can be named only with Alexander's OK for each use. Everyone else stays anonymous. Never state what a client paid.

Status key:
- **OK to use**: publish as-is with the caption given.
- **OK anonymised**: publish only with the anonymised label, and caption demo chats as demos.
- **NEEDS ALEXANDER OK**: real, but something (a client name, a third-party brand, faces, consent, or an unverified claim) needs his decision first.
- **DO NOT USE**: listed so nobody reuses it by mistake.

Companion data files (same folder): `appearances.json` (full evidence per event), `quotes.json` (verbatim quotes with line refs), `chats/*.json` (conversations).
