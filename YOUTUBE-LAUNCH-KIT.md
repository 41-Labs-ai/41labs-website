# Repurposing checklist (one page, run it per video)

Do this the same day you publish. Each video is one recording that becomes five assets. The loop is what makes it co-rank.

**1. Publish the video (5 min)**
- [ ] Title keyword-first, description pasted, chapters in, 12+ tags, thumbnail text set.
- [ ] Auto-captions on, then fix every brand-name spelling.
- [ ] Pin the demo comment. Add the end-screen card to the next video in the series.

**2. Embed it on the matching blog page (10 min) — this is the money step**
- [ ] Open the matching HTML file in `/Users/alexander/Projects/41labs-website/blog/` (filename = the blog slug in "Maps to").
- [ ] Drop the YouTube embed near the top of the article, under the intro. This gives the page a video band, lifts dwell time, and feeds the video views. Loop closes here.
- [ ] Video 7 embeds on the `/41-closer` page and on `can-whatsapp-ai-agent-close-sales` + `is-a-whatsapp-ai-chatbot-worth-it-singapore`.

**3. Audio-to-blog trick (Quaid's loop, 10 min)**
- [ ] Auto-transcribe the video (YouTube transcript export is fine).
- [ ] Clean up brand names in the transcript (same spelling fixes as captions).
- [ ] Paste the cleaned transcript under the matching article as a "Video transcript" section. Now the page and video share exact language, which strengthens the co-citation for that keyword.

**4. LinkedIn post, founder voice (10 min)**
- [ ] First person, Alexander. Lead with the pain, not the product. Plain English, no hype, no em dashes.
- [ ] One concrete number or example (a $30k renovation enquiry sitting unread; a 2am buyer who bought elsewhere).
- [ ] Native video upload if short enough, otherwise a strong thumbnail image + the YouTube link in the first comment (LinkedIn suppresses outbound links in the post body).
- [ ] Soft close: "Text it yourself, it replies to you: +65 8012 4848." Never "book a demo now".

**5. Helpful Reddit comment, only where a real thread exists (10 min)**
- [ ] Search r/singapore, r/smallbusiness, r/sgEntrepreneur, r/msp for threads asking about WhatsApp chatbots, Wati/Respond.io/AiSensy alternatives, or "how do I automate WhatsApp".
- [ ] Reference for what to write: our `blog/whatsapp-ai-tools-reddit.html` page.
- [ ] Answer the actual question first, honestly. Name the cheaper self-serve tools where they fit. Only mention 41 Closer if managed genuinely fits, and disclose you are the founder. Link the comparison article, not a sales page. No copy-paste, no spam. One good comment beats ten drops.

**Done when:** video is live, embedded on its blog page, transcript pasted under it, one LinkedIn post out, and at most one genuinely helpful Reddit comment where a real thread existed.
